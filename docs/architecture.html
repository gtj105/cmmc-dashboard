Key Data Flows

Authenticated Mutating Request

1
Page load sets CSRF cookie
middleware.ts → sets cmmc-csrf cookie if absent
2
apiFetch() attaches CSRF header
Reads cookie → adds X-CSRF-Token header automatically
3
Nginx rate limit check
limit_req_zone → 429 if threshold exceeded
4
API: CSRF + auth + role
checkCsrf() → getServerSession() → requireRole()
5
DB transaction + audit
Row-lock → UPDATE → INSERT security_events + practice_history
6
Structured log emitted
logger.security() → stdout JSON → Docker log rotation

Backup & Recovery Flow

1
Nightly cron at 2AM
backup service entrypoint.sh triggers backup.sh
2
pg_dump + evidence tar
Full DB dump + /evidence volume → /backups/daily/
3
SHA-256 checksum written
backup.sha256 file alongside each dump
4
Weekly verify (Sundays 6AM)
verify-backup.sh re-checks all checksums, logs pass/fail
5
Restore when needed
restore.sh --file backup.sql.gz --verify before applying
6
Factory reset (UI)
Admin → Backup tab → type RESET → restoreFromPayload(baseline.json)
