# .impeccable.md — CMMC Dashboard Design Context

## Design Context

### Users
CISO and security leadership at defense contractors. They use this daily to track compliance posture, brief program managers, and prepare for C3PAO assessments. They are expert users — they know what CMMC is, they don't need onboarding. They need to see the truth quickly and act on it.

### Brand Personality
**Precise. Composed. Credible.**

This is a professional tool for serious work. It should feel like Linear or Vercel — not a startup landing page, not a government IT system. The interface should communicate that the organization running it takes compliance seriously. When a CISO opens this before a board meeting, they should feel confident, not anxious.

### Aesthetic Direction
- **Feel**: Clean and confident. Dense where needed (tables, domain grids), spacious where it counts (overview KPIs, status indicators).
- **Theme**: Dark mode — but earned dark mode. Not "cool dark" with glowing cyan. A near-black with warm undertones, like high-quality print on dark paper.
- **Typography**: Should feel editorial/precision — not Inter default, not monospace-as-aesthetic. A geometric sans for data, something with personality for headings.
- **Color**: Muted neutrals as the base. Status colors (red/amber/green) reserved strictly for meaning — never decoration. No gradient text. No glowing accents.
- **References**: Linear's density and precision. Vercel's confidence and restraint. Bloomberg Terminal's information hierarchy (without the ugliness).

### Anti-References
- **AI slop dashboard**: Cyan on dark, gradient text on metrics, glassmorphism cards, glowing accents — this screams "AI generated" and undermines credibility with a CISO audience.
- **Government/compliance boring**: Gray tables, no visual hierarchy, looks like a spreadsheet — this fails to communicate program maturity.
- **Generic SaaS**: Overly rounded, white-on-white, feels like a startup pitch deck — wrong register for defense compliance.

### Design Principles
1. **Credibility through restraint** — every color, weight, and size choice should reinforce trust, not draw attention to itself
2. **Density with breathing room** — pack data where experts need it; give whitespace to the things that matter most (score, status)
3. **Status speaks through color** — red/amber/green carry full semantic weight; they should be the only bright things in the interface
4. **No decorative complexity** — if a visual element doesn't carry information, cut it
5. **Expert-first** — no tooltips explaining what "Audit Ready" means, no onboarding modals, no empty-state hand-holding
