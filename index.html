Capabilities

Everything the program needs.
Nothing it doesn't.

110 CMMC + 20 ITAR practices
Full CMMC Level 2 practice set pre-loaded across all 14 domains, plus a complete ITAR controls track. Set status, risk level, owner, due date, and notes on each practice. Filterable, sortable, audited.
DoD Assessment Methodology v1.2.1
Real-time SPRS score
Live SPRS score calculated from practice statuses using DoD weighting. Per-domain breakdown, historical trend, at-a-glance gauge.
POA&M lifecycle
Create findings, assign remediation plans, track milestone progress (0–100%), record responsible parties and resources. Full change history on every item.
Evidence management
Attach files or external URLs to any practice. Per-practice evidence drawer with assessment objective status tracking (met / partial / not met).
Microsoft overlay packs
Built-in mappings for Microsoft 365 GCC High, Azure Government, Defender, and Purview. See which CMMC controls are inherited vs. customer-owned.
Printable assessment report
Cmd+P (or Ctrl+P) renders a clean assessment report. No export wizard, no formatting issues — optimised print stylesheet, ready for C3PAO briefings.
Activity & audit log
Immutable record of every practice change, login event, and admin action. Who changed what field, from what value, at what time.
Automated nightly backups
Dockerised backup service runs pg_dump + evidence files every night. 30-day retention, weekly verification, one-command restore.

Security

Built for environments
that get audited.

A compliance tool that isn't itself secure undermines the program it tracks. Every layer has been reviewed against OWASP Top 10.

  • bcrypt password hashing 10 rounds, 12-character minimum, dummy hash on unknown users to prevent timing oracle attacks
  • Token revocation Per-token JTI blacklist on logout + per-user invalidation table on account deletion. Revocation enforced on every request.
  • CSRF double-submit cookies Timing-safe comparison via crypto.timingSafeEqual on all mutation endpoints (POST, PATCH, DELETE)
  • Database-backed rate limiting 5 failed logins → 15-minute lockout, tracked in PostgreSQL (survives app restarts). Nginx limits general API to 10 req/s.
  • Zod schema validation on every endpoint All mutating routes validate against typed Zod schemas before touching the database. Parameterised queries throughout — no raw SQL with user input.
  • Role-based access control viewer / editor / admin enforced at the API layer. Backup restore never imports password hashes; restored users must set a new password.
  • Docker secrets — never env vars PostgreSQL password and NextAuth secret stored as Docker secret files. Injected at runtime by entrypoint script, never written to environment or logs.
  • Content Security Policy + 12 Nginx headers Full CSP blocking inline scripts. HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, and more — all configured at the reverse proxy layer.

Deployment

Running in
under a minute.

One script handles secrets generation, database seeding, and first-run setup. Updates are a single command — migrations run automatically.

2

3
Updates: git pull && docker compose up -d --build Migrations run automatically at startup — no manual database steps
